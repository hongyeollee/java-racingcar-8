# java-racingcar-precourse


## 🚀 목표: 자동차 n개의 이름을 각각 부여하고 이동 시도 횟수를 설정하여 각 자동차의 무작위 값을 내부적으로 부여받아 무작위 값이 4 이상인 경우, 전진 하도록하여 가장 많이 전진한 자동차를 최종우승자로 선정한다.

## ⚙️ 기능목록
1. 경주할 자동차의 이름을 입력 받는다.
   - 1-1.프로그램이 시작되면 자동차 이름을 입력 받을 수 있도록 시작
     - 1-1-1. n개의 자동차 이름을 설정할 수 있고 쉼표(,)를 기준으로 구분하며 자동차 이름은 5자 이하만 가능하다.
     - 1-1-2. 자동차의 이름을 부여할때는 문자사이에 공백이 없도록 한다.(공백 발생시 자동으로 공백 없애도록 처리됩니다.)
   - 1-2. 예외규칙 발생시 IllegalArgumentException을 던진다.
     - 1-2-1. 이름 입력을 하지 않은 경우
     - 1-2-2. 입력 입력을 비어있는 경우
     - 1-2-3. 이름 입력을 5자 이상 입력한 경우
2. 이동할 횟수를 입력 받고 각 자동차 별로 시도 횟수별로 무작위 숫자를 부여받는다.
   - 2-1. 이동할 횟수는 차량별로 모두 같은 횟수를 부여받는다.
   - 2-2. 자동차별 이동하는 숫자는 0에서 9사이의 무작위 값을 부여받으며 부여받은 값이 4 이상인 경우에만 전진 이동이 가능하다.
   - 2-3. 예외규칙 발생시 IllegalArgumentException을 던진다.
     - 2-3-1. 시도 횟수에 1보다 작은 수를 사용한 경우(ex. 0, -1 etc...)
     - 2-3-2. 시도 횟수에 숫자가 아닌 값을 입력한 경우(ex. -a, ㄱ, % etc...)
3. 자동차별로 시도횟수에 대한 무작위 숫자를 부여받아 별도 정한 기준으로 전진한다.
   - 3-1. 무작위 숫자를 받은 자동차중에 숫자가 4이상 경우에 한 번 전진한다.
   - 3-2. 무작위 숫자가 4미만인 자동차는 전진하지 않고 제자리에 있는다.
4. 3번의 결과에서 각 자동차별 가장 많이 전진한 자동차를 우승자로 선정한다.
   - 4-1. 우승자는 한 명 이상일 수 있다.
   - 4-2. 우승자가 여러 명일 경우 쉼표(,)를 구분한다.
5. 4번의 결과로 나온 우승자로 결과를 도출한다.
